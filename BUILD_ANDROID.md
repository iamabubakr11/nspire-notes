# Сборка Android APK

Android-приложение Nspire Notes реализовано на Flutter. Установочный APK создаётся из исходного проекта с помощью Flutter SDK. Для сборки без локальной установки Android Studio используется GitHub Actions.

## Сборка в GitHub Actions

1. Создайте репозиторий и разместите в нём содержимое проекта.
2. Откройте вкладку **Actions**.
3. Выберите процесс **Build Android APK**.
4. Дождитесь завершения запуска для ветки `main` или запустите процесс вручную (**Run workflow**).
5. В разделе **Artifacts** скачайте архив `nspire-notes-android-apk`.
6. Распакуйте архив, чтобы получить `app-release.apk`.

Процесс сборки описан в `.github/workflows/build-android.yml` и включает установку среды Flutter, получение зависимостей, запуск тестов и сборку Android APK.

Если сборка завершилась с ошибкой, откройте соответствующий шаг в журнале Actions и устраните причину, указанную в логе.

## Публикация установочного файла

Для размещения APK с постоянной ссылкой можно использовать GitHub Releases:

1. Откройте **Releases → Draft a new release**.
2. Укажите тег, например `v1.0.0`, и название версии.
3. Прикрепите проверенный `app-release.apk`.
4. Опубликуйте релиз.

## Установка и проверка

1. Скачайте APK на Android-устройство.
2. Откройте файл в файловом менеджере и подтвердите установку из выбранного источника.
3. Создайте заметку с названием, датой, временем и текстом.
4. Проверьте редактирование, поиск и удаление записи.
5. Перезапустите приложение и убедитесь, что заметки сохранились.
6. Проверьте экспорт в JSON и импорт созданного файла.
7. Отключите интернет и повторите основные операции.

Экспортируемый JSON не шифруется. Для тестирования рекомендуется использовать вымышленные данные.

## Локальная сборка

Для локальной сборки потребуются Flutter SDK, Android SDK и Java, настроенные в соответствии с требованиями текущей версии Flutter.

```bash
flutter create --project-name nspire_notes --org dev.nspire --platforms android .
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

Готовый файл находится по пути `build/app/outputs/flutter-apk/app-release.apk`.
