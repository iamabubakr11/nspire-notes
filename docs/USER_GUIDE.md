# Руководство пользователя Nspire Notes

## Общие сведения

Nspire Notes — приложение для ведения записей во время рабочих встреч, совещаний и конференций. Заметки хранятся на устройстве и доступны без подключения к интернету.

## Главный экран

На главном экране отображаются список заметок, поиск, фильтры по категориям и кнопка создания записи. Закреплённые заметки выводятся в верхней части списка.

*Иллюстрация 1. Главный экран приложения — `screenshots/01-home.png`.*

## Создание заметки

1. Нажмите **«Новая заметка»**.
2. Укажите название, категорию, дату и время.
3. Добавьте текст заметки.
4. При необходимости включите закрепление.
5. Нажмите **«Сохранить заметку»**.

*Иллюстрация 2. Форма создания заметки — `screenshots/02-editor.png`.*

## Редактирование и удаление

Для изменения записи откройте её из списка, отредактируйте поля и сохраните результат. Для удаления выберите действие удаления и подтвердите операцию.

## Поиск и фильтры

Введите фрагмент названия, текста, категории или дату в поисковую строку. Для уточнения результатов используйте категории и календарный фильтр.

*Иллюстрация 3. Поиск по заметкам — `screenshots/03-search.png`.*

## Экспорт и импорт

**Экспорт:** откройте меню приложения и выберите **«Экспорт JSON»**. В системном меню укажите, где сохранить или отправить резервную копию.

**Импорт:** в меню выберите **«Импорт JSON»**, укажите ранее сохранённый файл и подтвердите добавление записей.

*Иллюстрация 4. Работа с резервной копией — `screenshots/04-backup.png`.*

## Проверка основных функций

| Проверка | Ожидаемый результат |
| --- | --- |
| Создание заметки | Новая запись появляется в списке |
| Редактирование | Изменённые данные отображаются после сохранения |
| Удаление | После подтверждения запись исчезает |
| Поиск | Отображаются записи, соответствующие запросу |
| Перезапуск | Ранее сохранённые записи доступны |
| Экспорт | Создаётся JSON-файл с заметками |
| Импорт | Данные JSON-файла добавляются в приложение |
| Работа без сети | Основные операции доступны без интернета |

## Установка Android-приложения

Инструкция по получению APK и установке на устройство приведена в [BUILD_ANDROID.md](../BUILD_ANDROID.md). Для воспроизведения интерфейса в браузере можно открыть `web-preview/index.html`; браузерный вариант использует `localStorage` вместо SQLite.
