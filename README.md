# Nspire Notes

Nspire Notes — мобильное приложение для рабочих заметок, встреч и проектных обсуждений. Разработано на Flutter для Android с локальным хранением и возможностью переноса записей через JSON-файлы.

## Возможности

- Создание заметок с названием, описанием, категорией, датой и временем.
- Редактирование и удаление записей с подтверждением.
- Поиск по названию, тексту, категории, дате и времени.
- Фильтрация по категориям и дате, закрепление важных заметок.
- Локальное хранение записей в SQLite (`sqflite`).
- Экспорт заметок в JSON и импорт резервной копии из файла.
- Интерфейс на русском языке, автономная работа без подключения к интернету.

## Технологии

| Компонент | Технология |
| --- | --- |
| Мобильный интерфейс | Flutter, Dart, Material 3 |

## Запуск

Требуются Flutter SDK и настроенные инструменты Android SDK. Разработку можно вести в Visual Studio Code.

```bash
flutter create --project-name nspire_notes --org dev.nspire --platforms android .
flutter pub get
flutter analyze
flutter test
flutter run
```

Чтобы собрать установочный Android-файл:

```bash
flutter build apk --release
```

Путь к APK после успешной сборки: `build/app/outputs/flutter-apk/app-release.apk`.

### Сборка через GitHub Actions

В `.github/workflows/build-android.yml` настроен процесс сборки на GitHub: установка Flutter, запуск тестов, создание APK и публикация файла в артефактах запуска. Порядок действий описан в [BUILD_ANDROID.md](BUILD_ANDROID.md).

## Структура проекта

```text
lib/
  main.dart             # Экраны приложения и пользовательские действия
  note.dart             # Модель данных и JSON-сериализация
  note_repository.dart  # Работа с SQLite
test/
  note_test.dart        # Модульные тесты
web-preview/
  index.html            # Облегчённая браузерная версия
.github/workflows/
  build-android.yml     # Сборка APK
```

## Браузерная версия

Файл `web-preview/index.html` можно открыть в браузере. В этой версии данные сохраняются в `localStorage`, а не в SQLite. Она предназначена для знакомства с интерфейсом; мобильные функции необходимо проверять в Flutter-приложении.

## Ограничения

Данные в SQLite и экспортируемом JSON-файле не имеют дополнительного шифрования. Для конфиденциальных записей необходимо отдельно реализовать защиту данных. Импорт резервных копий может добавить повторяющиеся записи. Облачная синхронизация не предусмотрена.
